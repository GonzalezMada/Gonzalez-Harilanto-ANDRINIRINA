Cette application démontre l'utilisation de TensorFlow.js pour la détection d'objets en temps réel dans le navigateur. Elle utilise le modèle COCO-SSD pré-entraîné et affiche les détections avec des boîtes englobantes et des étiquettes.

## Fonctionnalités

- Détection en temps réel via la webcam
- Affichage des boîtes englobantes et des étiquettes
- Interface utilisateur réactive avec Tailwind CSS
- Performance optimisée pour le navigateur

## Technologies

- TensorFlow.js
- COCO-SSD
- Astro
- Tailwind CSS
