This application demonstrates the use of TensorFlow.js for real-time object detection in the browser. It uses the pre-trained COCO-SSD model and displays detections with bounding boxes and labels.

## Features

- Real-time detection via webcam
- Bounding boxes and labels display
- Responsive user interface with Tailwind CSS
- Browser-optimized performance

## Technologies

- TensorFlow.js
- COCO-SSD
- Astro
- Tailwind CSS
